AirGuard – Air Quality Classification using Machine Learning

Project Overview

AirGuard is a machine learning-based web application that analyses air quality using pollutant measurements and classifies air pollution levels into three categories: Safe, Moderate, and Toxic.

The application uses a Random Forest classification model to predict air quality and provides an interactive dashboard through Streamlit.

Objectives

Analyse air quality based on pollutant concentrations.

Classify air quality into three categories.

Provide an interactive interface for air quality prediction.

Demonstrate the application of machine learning in environmental monitoring.
